System Diagnosis

Make system conflicts understandable.

A diagnosis maps the conflicts and dependencies shaping a system's current state and provides an explainable path through the assessment.

THE DIAGNOSTIC OUTPUT

From system conditions to an explainable assessment.

The work is organised around the question the customer needs to resolve. The result makes relevant relationships and conflicts visible and shows how they inform the diagnosis.

01 / DEFINE

Set the scope

Identify the system, the question to be examined and the relevant boundaries.

02 / MAP

Expose conflicts

Examine interactions, dependencies and constraints across relevant system dimensions.

03 / TRACE

Explain the assessment

Provide a traceable path connecting the starting conditions, identified conflicts and diagnostic conclusions.

TO BEGIN

Start with the system and the question.

  1. The system or situation to be examined.
  2. The key question or conflict to understand.
  3. Available information relevant to the case.

CONFIDENTIAL ENQUIRIES

Scope before disclosure.

Scope, deliverables, timing and commercial terms are clarified before work begins. Non-disclosure agreements (NDAs) are signed before confidential information is exchanged.
